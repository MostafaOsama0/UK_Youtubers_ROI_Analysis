# 📈 Influencer ROI Analysis for UK YouTubers

Welcome to the **Influencer ROI Analysis** project! This solution uses **Power BI** to deliver a dynamic simulation tool for marketing profitability and channel performance.


## 📄 Project Pages

## 🗂️ Project Overview
The goal of this project is to provide a comprehensive, interactive tool for **forecasting marketing campaign profitability** and rigorously assessing channel performance quality. It moves beyond raw metrics to model real-world financial scenarios.

---

## 💡 Key Features

1.  **Dynamic Simulation (What-If Analysis):** Utilizes Power BI "What-If" parameters to allow users to instantly adjust **Conversion Rate, Product Cost, and Cost Per Influencer** to test different scenarios in real-time.
2.  **Advanced Portfolio Modeling:** Implements DAX to calculate a **Dynamic Campaign Cost** based on the number of selected channels, ensuring accurate ROI for any custom portfolio.
3.  **Audience Quality Metrics:** Calculation and visualization of core engagement KPIs like **#Views Per Subscribers** and **Avg View Per Video**.
4.  **Integrated Storytelling:** Structured as a 2-page report to guide the user from the financial result (Profitability) to the cause (Performance Metrics).

---

## ⚙️ Analytical Workflow
The project follows a modern BI workflow:

1.  **SQL Preparation:** Cleaned and structured raw data into a clean View, ready for Power BI consumption.
2.  **Data Modeling:** Established a clean data model in Power BI.
3.  **DAX Execution:** Implemented complex measures to solve Filter Context and Row Context issues, ensuring mathematical consistency between individual channels and portfolio totals.
